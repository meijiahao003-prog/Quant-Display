# 主次连续合约：可审计的研究接口

本模块从研究笔记中重构了主次连身份、评分、状态转换、原始行情与比例复权，使用供应商无关的 pandas 输入。它不包含私人行情、凭据、数据库写入、外部接口或真实策略绩效。合成测试仅验证软件行为，不证明策略盈利。

## 已核实的规则

以最新主次连研究版本为基准：**30 天是“最后交易日减 30 自然日”的交割禁入窗口，不是 30 日滚动评分窗口。** 如果红线为休市日，生效日在红线当日及之后都不得选择该合约，自然等价于从其后第一个交易日禁入。

T 日收盘的评分为：

`OI权重 × 合格池内持仓量份额 + (1−OI权重) × 合格池内成交量份额`

分母只使用该角色在 T 日符合准入条件的合约。持仓量和成交量必须有限、非负；零值允许，零分合约允许补位。相同评分按交割月降序，再按完整合约标识升序确定，保证结果不依赖输入行顺序。价格缺失不会伪造评分数据。

| 参数 | 主力 | 次主力 |
| --- | --- | --- |
| 连续确认次数 | 3 个连续交易日 | 5 个连续交易日 |
| 换约条件 | 同一候选严格超过现任评分 1.2 倍 | 同一候选严格超过现任评分 2.0 倍 |
| 默认持仓量权重 | 0.80 | 0.80 |
| 默认成交量/持仓量准入下限 | 0 / 0 | 0 / 0 |

保留分组持仓权重：贵金属 0.30、有色 0.50、农产品/鸡蛋及默认品种 0.80、能源化工及广期所研究品种 0.75；`strategy_for_product` 返回这组研究参数，不代表官方或经收益验证的参数。两个角色可以独立配置。

所有选择在 **T 的下一交易日** 同时生效；首个输入日不构造使用当日收盘信息的同日主连。任一现任失格时，整对按各自合格池重选；次主力不得与主力重复，合格池不足则留空。主力普通换约时，次主力立即重选并清除确认状态。交易日历中整日行情缺失会打断确认；禁止把缺失交易日从状态机中跳过。

## 输入、时点与复现

```python
from futures_research.continuous import build_continuous, canonical_id

# bars、catalog 为用户已授权并整理的 pandas DataFrame。
# calendar 为用户明确提供的交易所交易日 DatetimeIndex。
result = build_continuous(bars, catalog, calendar)
mapping, raw, adjusted, rolls, scores = (
    result.mapping, result.raw, result.adjusted, result.rolls, result.scores
)
```

| 输入 | 必需字段或约束 |
| --- | --- |
| `bars` | `date, contract_id, open, high, low, close, volume, open_interest`；合约/交易日唯一 |
| 可选行情字段 | `available_date` 默认等于 date，表示该日收盘可得；`suspend_flag` 默认 0，明确传入时只能 0/1 |
| `catalog` | `contract_id, exchange, product, delivery_month, list_date, last_trade_date, known_at, source` |
| 元数据版本 | 同一合约可有多个版本；`contract_id/known_at` 唯一；每次决策只读取 `known_at <= T` 的最新版本 |
| 可选保护字段 | `first_excluded_date` 只能将红线提前；来源及知晓时点必须随该版元数据记录 |
| `calendar` | 至少两天、唯一、严格递增的显式交易日；覆盖每个行情日期及最后行情日的下一交易日 |

日期使用无时区、午夜、完整日期表示交易日；拒绝未声明单位的数字时间戳。此处 `known_at` 是“该元数据在该日决策时已知”的日级声明，不是系统自动核实的证据；导入方必须保存源文件、发布时间、交易日历来源与修订历史。若没有历史快照，不得用今天下载的最终到期日冒充过去已知的 metadata。

`canonical_id("DCE", "M", "2027-01-01")` 返回 `DCE:M:202701`。郑商所三位代码必须先由有日期证据的目录解析完整交割年份；不能按全样本最后日期猜测十年。身份包含交易所、品种和完整交割年月。

`normalize_bars` 支持显式 `column_map`、`volume_multiplier` 和 `open_interest_multiplier`。历史单双边计数变化须由调用方按有证据的日期分段转换；一个全局系数不等于完成历史口径校正。重复键、畸形数值和未解释的交易日期冲突直接失败；真实缺失保留缺失，不采用“保留最后一条”隐式覆盖。

`adapters.load_daily_inputs` 只读取调用者明确指定的三份 CSV，并返回对应内容的 SHA-256；日历 CSV 使用 `date` 列，不自动联网或扫描目录。`audit_daily_coverage` 按当时已知的上市/最后交易日期逐日检查行情，区分 `AVAILABLE`、`MISSING_BAR`、`LATE_BAR` 和有行情却尚无可用目录信息的 `UNKNOWN_METADATA`。它检查行情完整性，因此交割禁入期内仍审计行情，不能把“选约已排除”误判为“不需要原始数据”。

`available_date` 晚于所属交易日的行情不能用于当日评分、当日原价特征和桥接。当前实现按单个不可变行情快照重放，不支持对迟到修订数据自动恢复历史状态；应固定输入版本并记录哈希。日级日期也不足以模拟夜盘、盘中发布或具体订单时间，此时需要另外实现时间戳级的数据可得性和执行模型。

## 输出与价格边界

- `mapping`：决策日、生效日、主次角色、当前和前任完整合约标识、动作、确认次数与硬重置标记。最后一次决策可对应尚无行情的下一日。
- `raw`：按已确定的生效日合约读取当天 OHLC，记录 `bar_present/bar_available`；不前填、不生成平 bar。真实缺失或尚未可得的价格维持 NaN。
- `scores`：每个交易日、角色、候选的准入结果、淘汰原因、份额分母及评分，以及本次使用的元数据版本。
- `rolls`：角色、换约生效日、前一交易日桥接价格、换约比率、累计因子与断裂状态。
- `adjusted`：保留原价列，并另列 `*_adjusted`、`daily_multiplier`、`factor` 和状态。

最新笔记虽然沿用“后复权”命名，实际算式是**首段锚定、向前累计**：T+1 换约时，以 T 日两个合约的收盘价计算 `factor *= old_close(T) / new_close(T)`。本实现命名为 `causal_ratio_adjust`，追加未来换约不会改写已生成历史价格。没有换约时乘数是 1；不沿用原输出中“0 代表无换约”的混淆编码。

桥接价格缺失、非有限或非正时，该角色复权因子从断点开始失效，后续不自动恢复、不用未来价格回填、不以前值伪装成交。非正期货价格在市场上可能存在；比例法对此不适用，原价仍可保留，需另选有明确定义的收益或差额拼接方法。

**原价主连的换月跳变、连续复权价格涨跌，都不能直接认定为可交易策略收益。** 换约真实损益取决于持仓、合约乘数、平旧开新的成交时间及价格、点差、手续费、滑点和保证金。下游回测必须按合约账本处理，并明确收盘信号通常只能在之后的可交易时刻执行。本文的 T+1 仅定义合约映射，不承诺 T+1 开盘价格能够成交。

若另外生成“以最后一段为锚、把以后换月信息乘回早期价格”的全样本复权，则只能作为展示或带 `as_of` 版本的研究产物，不能直接作为当时可见的模型特征。

## 与原笔记的明确差异

这是经过约束的公共研究内核，不声称完整复刻供应商工作流：

1. 不移植本地优先/API 补数、数据库发现、缓存回放、外部主连比对、账号连接和报表写入。公开代码不访问私人环境。
2. 不移植早期主连版本中的全样本日均成交额筛选、按样本末日推算年份、当日收盘选约作用于同日行情、交割边界兜底和造平 bar。这些做法可能引入未来信息、存活偏差或不可交易价格。
3. 最新版本使用 volume 份额；早期版本使用 amount 份额、双第一快速通道、冷却期和禁止回头，属于不同策略规则，未混合使用。
4. 不把当前交易所规则列表追溯应用为历史事实；依赖调用方提供已核实、带来源和知晓时点的逐合约生命周期及提前禁入记录。没有自动交易所规则下载或法律有效性核验。
5. 不使用与“日历文件末端减十天”绑定的临时远期保护守卫，以免扩展未来日历时改写历史选择。基于显式最后交易日直接比较固定红线，日历必须覆盖实际生效区间及下一交易日。
6. 省略自动前填复权 OHLC；缺失以缺失和断裂状态交付。输入行顺序和未来样本追加不得改变已产生历史。

合成测试覆盖 T+1、严格确认阈值、红线、元数据可得性、缺失交易日、重复输入、桥接断裂和未来追加的前缀不变性。真实数据验收仍需检查官方日历完整性、历史上市/退市/交割公告、数据发布延迟、夜盘归属及供应商口径。
