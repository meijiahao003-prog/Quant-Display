本次依据用户提供的 17 份研究文件整理公共代码：7 份 Notebook、10 份 Python 模块。原件仅用于只读核验，没有执行其中的数据库连接、行情补数、训练任务或写入操作。公开版使用重构函数、包内模块、文档和合成测试，不原样打包私人研究目录。

## 公共接口

行情模块接收显式 pandas 表或明确指定的 CSV，不自动探测数据库、读取凭据或调用行情服务。单位换算、目录版本、日历和提前交割禁入信息通过契约提供，并记录来源和当时可用时间。

模型通过配置及本地数据运行，公开示例只含通用参数和相对路径。实际账号、密钥、连接串与授权数据由私有接入层管理，不填入源码或示例配置。

Git 忽略规则排除数据、运行输出、常见权重/序列化状态与环境配置。忽略规则不会自动删除已跟踪的敏感文件，仍需检查实际变更集合。

## 发布检查

```bash
python tools/check_public_release.py
```

检查结合文件白名单与文本规则，识别私人绝对路径、IP、邮箱及常见凭据赋值。命中仅报告文件、行号和类别，避免把疑似秘密值再写入日志。它不保证发现所有凭据变体、专有算法、商业秘密、许可限制或可重新识别的信息。

提交前人工审阅文件及 Git diff，确认没有真实样本、Notebook 输出、截图、日志、权重、私人配置或未经授权的成果混入。公开文献链接、通用字段和合成标识不等于私人数据，不能用批量替换敏感词代替内容审查。

真实运行产物可能包含合约、样本时间、目标、预测、特征名和本机产物路径，应留在本地忽略目录。公开源码不等于授权自动公开下一次生成的研究结果。

脱敏不会撤销已在其他渠道泄露的凭据；本次没有验证或使用任何原始凭据。当前没有新增开源许可证，后续使用与分发应按实际代码、数据和第三方材料权利来源处理。通过扫描不能证明所有内容可无限制再分发。
