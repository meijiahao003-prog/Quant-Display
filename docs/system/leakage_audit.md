# 全系统数据泄漏与逻辑复核

本轮以公开版本 `fe77ce2d48622fa43a17d4aae3574f5621aa22a0` 为基线，复核训练、时间融合、CTA 信号与研究回测，并检查预处理、采样、连续合约及因子快照桥接。以下为可复现问题及修复；通过检查不等于证明供应商数据或所有研究决策没有前视。

## 已修复的问题

| 问题 | 原有影响 | 修复后的行为 |
|---|---|---|
| 验证 IC 并非逐轮计算 | XGBoost / LightGBM 每 30 轮更新 IC，其余轮复用旧值，下游可能据此选错轮数 | 每轮记录真实 IC；回归直接对照同一 Booster 各轮预测 |
| 序列模型忽略独立 IC 标签 | Transformer / iTransformer 用变换后的训练标签计算本应对原始收益的 IC | 独立 `ic_y` 与排序后的窗口终点对齐，不影响训练窗口或损失 |
| 目标单位混用 | 提供 `ic_y` 时测试 RMSE / MAE 也切换到该标签 | 误差对训练目标计算，IC 对独立标签计算；预测表分别保存 `target` 和 `actual` |
| Test 的未来标签决定预测成员 | 根据 `label_end` 清理 Test 行，间接改变截面排名与仓位 | 预测只按冻结的决策区间与特征可用性生成；缺失或越期标签只遮罩指标 |
| 未定义指标阻断合法预测 | 标签全缺失、常数或月度 IC 未定义时整次评估失败 | 保留预测，指标为 NaN，审计注明未定义；不填零或伪造指标 |
| Fit 增广依赖未来合约范围 | 只在 Valid / Test 出现的合约也改变 Dirichlet 维度与历史增强样本 | 固定权重只由标签合规的 Fit 合约生成 |
| 不完整板块基准 | 缺少板块成员收益时仍可能用剩余成员估计中位数 | 当时研究范围中任一成员标签未知，则该板块相对目标未知，特征与信号保留 |
| 残差晋级跨 Test 标签 | 晋级样本日期合规，但收益尚未在 Test 前实现，仍被用于选组 | 晋级选组只用 `label_end < test_start` 的标签，并在测试入口复查 |
| 预处理来源被覆盖 | 先做未来拟合变换，再做较早截止的变换，会覆盖 attrs 中的未来时间 | 公共 fit / transform 和编排均核验上游来源，不能以新时间覆盖已知的晚期拟合 |
| 模型冻结时点不完整 | 仅检查最后训练观测，稀疏数据可能允许早于声明冻结时点的预测 | 同时检查实际训练标签截止和声明 `fit_as_of` |
| OOF、计划及缓存绑定不足 | 改动 OOF 内容、折归属、元数据或回调后，可能继续使用旧审计/缓存 | 校验内容、标签、折、特征、时点与模型计划；缓存包含回调代码和运行库版本 |
| 回测收益超出报告窗口 | 使用声明 Test 截止之后的执行结果公布损益 | 直接拒绝越界报告，不根据未来收益剪掉持仓；仅实际持仓结果决定净值可得时间 |
| 尚未知晓的净值被再投资 | 上一期结果晚到，下一期却已按包含该结果的权益配仓 | 上期持仓结果必须在下期区间开始前可得；曲线记录 `equity_available_at` |
| 不可能的信号时间 | 低层组合 API 接受早于决策时点的信号可得时间 | 信号不得早于决策，收益区间不得早于信号可得时间 |
| 股票 Rank IC 的缺失值口径 | 两侧分别排名后才取交集，造成秩间距失真；维度广播可静默重复标签 | 先取共同有限资产，再分别排名；必须提供相同二维形状 |

另收紧直接目标列进入特征、重复资产/时点身份、种子与训练轮数类型检查；运行配置深拷贝，避免延后 loader 修改已经冻结的嵌套配置。

## 验证设计

本轮新增测试不仅检查返回值，也主动扰动不应影响既有结果的信息：

- 改变 Test 的标签数值、缺失状态及结束时间，预测、集成排名、目标仓位和独立执行收益下的研究曲线不变。
- 添加只在未来区间出现的合约，不改变已有 Fit 增广样本。
- 向预处理重复调用链注入未来拟合来源，必须在继续训练前拒绝。
- 将 OOF 预测改为真实标签、篡改折归属或时间声明，必须拒绝继续训练元模型。
- 将晋级标签结束时间推迟到 Test 内，不能参与晋级选择。
- 延迟上一期持仓收益可得时间至下一期开仓之后，必须拒绝按未知权益复利；零仓位的未知结果不应阻断计算。
- 将独立 IC 标签与训练标签设成不同单位/方向，核对树模型各轮、序列窗口及误差指标口径。

具体数量、命令和平台记录见[验证记录](../futures/verification.md)。所有本轮训练与回测验证均使用合成数据，原始私人 Notebook 和真实市场数据未执行。

## 对已有研究结果的影响

修复会改变部分选中轮数、IC / RMSE、Test 覆盖、增强样本以及受影响的研究净值。旧结果不能与新版本无差别混用，也不能只保留修复后更好的结果。旧 OOF 或缓存缺少新审计绑定字段时，应重新生成；本地结果使用新目录，保留原版本来源。

本轮不重算原股票因子历史结果档案。Rank IC 的修复适用于今后计算，旧档案仍是未重新核验的历史材料。

## 仍需外部证据的边界

- 调用者声明的 `feature_available_at`、`label_end`、板块/主次力映射及供应商历史版本真实性，仍需原始数据证据；去掉 attrs 或填写虚假的时间不会被数学检查自动识别。
- 先前是否已查看 Test、如何选取板块/因子/模型与交易规则，函数无法独立取证；反复研究同一 Test 后必须另留未查看区间。
- 分层 `run_research_walk_forward_test` 会按月加入已实现的过去测试标签，是滚动研究评估；通用流水线与 CTA 的最终 Test 则使用已冻结模型。
- 原生模型对象在外部被再次 `fit/update` 的行为不在当前状态校验范围内。API 校验最终阶段、对象身份、配置、列顺序和时间协议；保存文件及运行指纹用于追溯，不能将其表述为不可修改的对象。
- 自定义训练/预测回调的可变外部状态无法由代码哈希证明；状态变化时使用新运行目录并禁用旧缓存恢复。
- 研究回测仍是非重叠区间、每期独立开平的名义收益账本。它不模拟真实撮合、保证金、盘中强平、容量或移仓。未提供收益可得时间时按 `return_end` 已知处理，这是需数据方确认的假设。
- 本轮实际后端覆盖 XGBoost、LightGBM 和 CPU Torch；CatBoost、GPU 以及真实市场有效性不在已完成的验证范围。
