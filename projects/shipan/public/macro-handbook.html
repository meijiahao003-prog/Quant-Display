宏观层面股市风向研究框架

政策与流动性传导 · 每日监测清单 · 研报交叉验证 · 自上而下研究流程 ｜ 生成日期 2026-10-23
使用说明（TL;DR）

本手册把"判断股市整体风向"拆成四层可执行的工作：① 政策层（央行与财政在做什么）、② 流动性层（资金量价是否真的宽松）、③ 市场层（广度、情绪、量能是否支持行情）、④ 验证层（研报与数据交叉检验，明确证伪信号）。每日投入约 40 分钟（盘前 15 + 盘后 25），每周输出一页纸结论。核心原则：传导链必须写全中间变量，判断必须附证伪条件——"流动性宽松利好股市"这类一句话结论不构成研究。

一、政策与流动性分析：工具箱与传导链

宏观政策对股市的影响从来不是直线。下面按工具逐一给出传导链，箭头不可跳步；每条链同时标注观察确认点（用来验证传导是否真正发生）与失效情形。

1.1 公开市场操作（OMO，逆回购）

7天逆回购净投放/回笼 + 利率→ 银行间资金面（DR007）→ 短端利率 & 同业存单成本→ 市场风险偏好 / 杠杆资金成本→ 股市估值中枢（尤其成长股）

观察要点：每个交易日 9:20 央行公告。单日操作意义有限——OMO 是削峰填谷工具，月末、季末、税期大额净投放不代表政策转向。真正要看的是：① 7 天逆回购利率是否调整（政策利率锚，调整即重大信号）；② 剔除到期量后的跨周期净投放趋势；③ DR007 是否持续偏离政策利率（持续低于 → 资金面实质宽松）。

失效情形：资金面宽松但实体信用需求疲弱（"资金淤积银行间"），宽松无法传导至权益市场盈利预期。

1.2 MLF（中期借贷便利，每月 15 日）

MLF 量（超额/缩量续作）+ 利率→ 银行中期负债成本→ LPR 报价预期 / 信贷投放能力→ 宽信用预期 → 企业盈利预期

观察要点：超额续作且利率下调 = 双宽信号；缩量平价续作常见于资金面已松、防止空转。注意 MLF 的政策利率色彩近年淡化，利率信号更多看 7 天逆回购利率，MLF 主要看量。

1.3 存款准备金率（降准）

降准释放长期低成本资金→ 银行可贷资金 & 负债成本下降→ 信贷扩张能力 / 债券配置力量增强→ 长端利率下行 + 宽信用预期 → 股市（尤其顺周期、金融）

观察要点：降准是信号意义大于资金意义的工具——0.25~0.5 个百分点释放的长期资金规模相对 M2 不大，但它标志货币政策立场。历史上降准公告后首个交易日市场高开概率较高，但持续性取决于是否配套宽信用。单独降准而无财政/信贷配合时，行情常"一日游"。

1.4 利率政策（LPR 每月 20 日、存款利率、存量房贷利率等）

LPR / 贷款利率下调→ 实体融资成本 + 居民房贷负担下降→ 企业盈利改善预期 / 消费地产企稳预期→ 分子端（盈利）与分母端（贴现率）双利好

观察要点：① 5 年期 LPR 挂钩房贷与地产链；1 年期挂钩短贷与企业流动性。② 降息对股市的净效应 = 贴现率下降（+）与银行净息差受压（−，利空银行权重）的合成。③ 存款利率下调是被低估的变量：它推动居民存款向理财/货基/权益迁移，是增量资金的慢变量。

1.5 财政政策（赤字率、专项债、特别国债、化债）

财政发力（发债+支出提速）→ 基建/设备/民生需求落地→ 相关行业订单与盈利（一阶：建筑建材机械；二阶：上游材料、下游消费）→ 盈利驱动的指数行情（区别于纯流动性行情）

观察要点：财政的效果需要数据验证，传导时滞通常 1~2 个季度。跟踪链条：发债节奏（专项债发行进度）→ 财政存款变化 → 基建类订单/挖掘机销量/水泥价格等高频实物量。警惕"政策意图 ≠ 政策兑现"：化债类政策改善的是资产负债表而非需求，对盈利的传导更弱。

三条通用警示（适用于所有政策解读）：
① 市场提前定价：政策正式公布时常已"买预期卖事实"，公布日反向交易并不少见。判断行情阶段比判断政策方向更重要。
② 同一政策在不同周期传导方向可能相反：弱市中的降息可被解读为"经济比预期差"而利空。必须结合当时的经济位置与市场预期差。
③ 区分流动性行情与盈利行情：前者弹性大、终结快（靠分母）；后者慢而持久（靠分子）。两者需要的验证指标完全不同。

二、每日数据监测清单

按"盘前 / 盘中 / 盘后"三个时点组织，每项标注观察要点与异动含义。建议做成固定模板每日填写，连续记录后指标的趋势与拐点会自然浮现——单日数值几乎无信息量，序列变化才有。

2.1 盘前（8:30–9:25，约 15 分钟）

关键词 / 指标来源方向观察要点与解读
央行 OMO 公告（9:20）央行官网操作规模 vs 当日到期量 → 净投放/回笼；利率是否变动（变动即头条级事件）
隔夜美股 + 中概股行情终端/财经媒体纳指/标普涨跌、费城半导体、金龙指数；影响开盘情绪与科技板块映射
离岸人民币（USDCNH）行情终端快速贬值 → 压制风险偏好与外资意愿；升值反之。关注 7 天内的方向而非单日
国债期货 / 10Y 国债收益率行情终端收益率快速下行 = 避险/宽货币预期升温；债股跷跷板 vs 债股双牛要分清
大宗商品（铜/油/黄金）行情终端铜 = 全球需求温度计；黄金新高常伴随避险情绪；油影响通胀预期
当日事件日历财经日历当日是否有经济数据发布（PMI/CPI/社融窗口）、MLF/LPR 操作日、限售解禁高峰

2.2 盘中与收盘核心指标（15:00 后整理）

类别指标观察要点与异动含义
量能与广度两市成交额万亿是情绪分水岭的经验线；缩量上涨警惕、放量滞涨警惕；连续 3 日趋势比单日重要
涨跌家数比 / 新高新低家数指数涨但跌家数多 = 权重硬拉、广度恶化，是行情脆弱的前置信号；广度恶化常先于指数见顶
涨停/跌停家数、连板高度短线情绪温度计；跌停数骤增是恐慌信号；连板梯队断裂预示题材退潮
资金面两融余额（T-1 日数据）融资余额快速攀升 = 杠杆情绪升温（助涨也助跌）；融资买入额占成交额比重超 ~10% 经验上偏热
北向资金注意口径变化：2024-08-19 起沪深交易所不再披露北向实时资金流与每日净买入，盘后可看成交总额、季度披露持仓。每日跟踪应改用"沪深股通成交占比"衡量外资活跃度，辅以 EPFL/EPFR 类外资流向数据（周频）
ETF 份额变化 / 大资金申购宽基 ETF（沪深300/中证500 等）份额异动常反映"国家队"与配置资金动向；下跌中份额逆势大增是托底信号
情绪与衍生品股指期货基差（IF/IH/IC/IM）深度贴水 = 对冲需求旺盛/悲观；贴水快速收敛常对应情绪修复
期权隐含波动率 / PCR50ETF/300ETF 期权 IV 急升 = 恐慌；Put/Call 比率极端值有反向指示意义
换手率 / 破净率全市场换手率极端高位对应情绪顶部区域；破净股占比是底部区域的慢变量
结构与风格行业涨跌排行 / 领涨主线判断行情性质：全面扩散（健康）/ 局部抱团（脆弱）/ 防御走强（转弱前兆）
大小盘 / 成长价值风格中证2000 vs 沪深300、国证成长 vs 价值的相对强弱，确认风格是否与宏观判断一致

2.3 资金面利率（每日 1 分钟扫描）

指标含义 / 观察要点
DR007银行间真实资金价格；持续低于 7 天逆回购利率 = 资金面实质宽松

时点事件关注点

建议固定跟踪：宏观团队（政策解读与大类资产）、策略团队（市场大势与风格）、固收团队（流动性与利率，对资金面的刻画通常比股票团队更细）三类各 1–2 家。团队人事变动频繁，以最新任职为准，不迷信单一明星分析师。

3.3 交叉验证三原则

  • 多空各读一篇：对同一事件（如一次降准），至少读一篇乐观解读与一篇谨慎解读，记录双方的核心假设分歧——分歧点就是你需要自己用数据裁决的地方。
  • 观点对照持仓：策略团队的观点要对照其推荐主线的历史胜率；券商观点存在系统性乐观偏差（sell-side bias），"谨慎"措辞在卖方语境中往往已接近看空。
  • 观点必须能翻译成可证伪命题：把"流动性宽松利好成长股"改写成"若未来 4 周 DR007 中枢下移且 M1 回升，则成长/价值相对收益应为正"，到期回看打分。无法改写的观点没有研究价值。

四、自上而下研究框架（六步法）

1
宏观定位：增长 × 通胀象限

用 PMI / 工业增加值 / 社融（增长维度）与 CPI / PPI（通胀维度）判断当前处于"复苏 / 过热 / 滞胀 / 衰退"哪个象限，辅助以库存周期（工业企业产成品库存）与信用周期（社融存量增速方向）。输出：一句话定位 + 依据数据 + 上次切换时间。

2
政策周期判断：货币 / 财政 / 监管三条线

分别评级"宽松 / 中性 / 收紧"，依据是第一部分的工具箱与政策措辞边际变化。三线共振（如货币+财政双宽）的历史胜率显著高于单线发力。输出：三线评级表 + 最近的政策拐点事件。

3
流动性验证：量与价分开看

量的宽松（降准、净投放、M2/社融增速）与价的宽松（DR007、存单利率、10Y 收益率下行）是否同步发生？只量不价（资金淤积）与只价不量（被动宽松）都是弱信号。关键校验点：M1 增速——M1 回升代表企业活期资金活化，是流动性真正进入实体与市场的标志。

4
市场状态分档：进攻 / 震荡 / 防守 / 切换

综合：① 指数趋势与位置；② 市场广度（涨跌家数、新高新低、行业参与度）；③ 情绪温度（成交额、两融、换手率、IV）；④ 主线清晰度。规则：指数涨 + 广度差 = 脆弱档；广度恶化先于指数回落，是最重要的前置信号。状态不清晰时明确写"切换中"，不强行分档。

5
风格与主线映射

把 1–4 步结论映射到风格：利率下行 + 宽货币未宽信用 → 成长/长久期资产占优；宽信用见效 + PPI 回升 → 顺周期/价值占优；政策主题驱动 → 按"政策 → 行业 → 公司"传导链选一阶/二阶受益。映射必须写出完整链条，禁止"都受益"。

6
写出证伪条件与切换信号

每个判断附三行：维持条件（什么不变就继续持有该判断）、前置信号（哪些指标先动预示切换，如广度掉头、存单利率拐点）、失效标志（哪条线被打破就重写判断，如"M1 连续两月回落则盈利行情假设作废"）。没有证伪条件的判断等于没有判断。

每周一页纸输出模板（建议固定）

  • ① 宏观定位（象限 + 依据，3 行）
  • ② 政策三线评级（货币/财政/监管 + 边际变化）
  • ③ 流动性量价状态 + M1 方向
  • ④ 市场档位 + 广度/情绪关键读数（与上周对比）
  • ⑤ 风格判断 + 传导链（1 条，写全）
  • ⑥ 上周判断回顾打分（兑现/部分兑现/证伪）+ 本周证伪条件
常见研究偏差自查清单：
① 确认偏误——只读与自己观点一致的研报（对策：强制多空各一）；
② 叙事替代数据——被流畅的宏观故事说服而未核对数据时点与口径（对策：每个关键数字标注来源+时点）；
③ 后视镜偏差——用已发生的行情倒推政策解读（对策：判断必须事前写下，事后打分）；
④ 单日噪声过度解读——政策日/数据日的当日行情方向预测错误率过半，改为"观察框架"而非"方向预测"；
⑤ 忽视披露口径变化——如北向资金（2024-08 起每日净买入不再披露），旧口径的数据源会给出陈旧或错误的信号。
