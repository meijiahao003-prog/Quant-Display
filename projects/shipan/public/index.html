行情与资金数据源

腾讯提供指数 / ETF 走势，东方财富提供当天主力、超大单和大单资金分时。打开或切换标的时补拉当天已有分钟数据，无需填写 Token；页面可见时每 60 秒刷新；北京时间跨日、切回页面或恢复联网时立即重拉。盘前、休市或源未更新时，保留并标注实际行情日期。

留空访问本站内置行情服务。自定义服务需使用 HTTPS；本地使用自带页面可同源访问。
如何在本地启动？

下载项目源码，按照 README 安装依赖并启动 FastAPI。使用本地地址打开工作台，无需跨域配置。网络需能访问东方财富等行情源。

python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000

然后打开 http://127.0.0.1:8000 。公网运行请在反向代理配置 TLS 与认证。

数据边界

价格与走势来自腾讯，资金分时来自东方财富。曲线展示当日累计净额；指数使用上游指数资金口径，ETF 使用自身交易资金口径。上游缺失分钟保持空档，失败时注明缓存。主力是大单与超大单统计，不等于机构账户或 ETF 申赎。免费源延迟及可用性不作保证。
