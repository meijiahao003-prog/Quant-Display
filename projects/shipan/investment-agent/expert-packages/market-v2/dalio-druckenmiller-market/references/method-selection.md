# 方法选择与冲突处理

本文件全部为我们的A股应用设计，不是原作者给出的分类器或经过回测的策略。方法卡中的适用与失效条件同样是工程边界。先认清问题所处层次，再决定哪些方法有用。

## 按证据选方法

| 当前观察与问题 | 优先借用的思路 | 需要的额外证据 | 应当降级或停止套用的情形 |
|---|---|---|---|
| 政策/宏观变化，板块受益方向未清 | Dalio/Bridgewater的预期和传导，Druckenmiller的融资与反馈 | 政策实施、受益链条、事前预期、盘面反应 | 只有口号；没有需求/盈利路径；低频数据被用于预测分时买点 |
| 已有成长板块领涨且内部扩散 | Ryan的筛选与计划；Minervini的研究覆盖和选择性；Druckenmiller的反馈 | 同期基准、多日个股和板块走势、相关盈利/公告、可执行失效点 | 单日孤立拉升；指数强但候选持续弱；卖出条件无法实现 |
| 商品或产业价格变化，寻找A股受益链 | 傅海棠与林广茂的供需问题拆解 | 库存口径、供需/政策、上下游成本和售价、公司真实敞口 | 商品涨价只推高成本；名义库存不可用；期货交割逻辑无法映射股权 |
| 方向混杂、区间内反复、缺少连续领涨 | Raschke的准备/多周期观察，Brandt的候选与实际持仓分离 | 清楚的区间、事件和观察计划 | 没有区间数据却硬说均值回归；用日内经验推导数周优势；突破后仍按旧区间逆势 |
| 恐慌下跌而估值看似便宜 | 葛卫东的价值与交易周期反思；Soros的信用反馈；Druckenmiller的修正 | 资产负债、盈利质量、融资条件、流动性与价格企稳证据 | 困境导致估值基准失真；被迫卖出反馈未缓和；“便宜”被当成时间保证 |
| 已有持仓反复亏损、临时改规则 | 青泽的系统与自我约束；Brandt的风险记账；Haskell案例的计划记录 | 原计划、实际行为、风险敞口、交易成本和可卖数量 | 没有原记录却事后重写；把风控流程误称有预测优势；为回本延长周期 |

选择只是让分析更聚焦。宏观中性时仍可能出现局部波段；市场弱时强势股也未必满足账户执行条件。不存在“某位看多抵消另一位止损”的算法。

## 分歧的处理顺序

先检查数据与口径，再判断分歧属于时间尺度、投资对象还是方法假设。保留不能解释的冲突，不通过添加叙事强行统一。

- **宏观改善，价格持续弱**：宏观作为背景保留，核对是否已计价、传导滞后、融资挤出或个体问题；交易计划按自身价格/时间失效条件更新，不能无限等兑现。
- **价格强，宏观证据弱**：可列局部交易候选，说明持续性证据和反证；不把局部上涨宣布为宏观反转。
- **供需论点与趋势相反**：傅海棠材料中的基本面取向与技术筛选确有差异。可以用供需生成研究候选、另用A股价格和执行约束决定是否参与，但明确这是一套自建组合流程，不说所有人原本赞同。
- **估值便宜与相对弱势冲突**：葛卫东的长持有回顾提醒波段有机会成本，但当前技能仍按数日到数周处理；用户要改成长持有时才改变目标，不擅自将失败波段转成价值投资。
- **形态成立与账户不参与**：Brandt报告显示研究判断和实际风险承担并不等同。没有清晰可承受损失、可执行退出或合适流动性时，观察清单可以保留，实际行动可以不成立。

## 失效分三层

1. **事实失效**：关键公告/供需/盈利等与原假设相反，更新机会论点。
2. **交易失效**：事先定义的价格、流动性或执行条件被破坏，即使宏观故事尚在也单独处理。
3. **时间失效**：约定催化未出现或强弱未发展，重新评估；不是越跌越延长期限。

“何时重新评估”与“无条件市价卖出”不同；实际持仓处理仍取决于用户目标、交易制度和可成交条件。长期产业判断不能被单根K线逻辑上证伪，短线执行也不能借长期故事免于审查。

## 复盘记录字段

用户要求留档时保存下列最小内容；没有的数据用未知，不补造：

`record_id / created_at / analysis_asof / timezone / instrument_scope / horizon / mode`

`source_urls / source_publication_time / source_version_or_hash / market_data_asof / raw_inputs / calculation_formula`

`selected_method_ids / sourced_principle / a_share_adaptation / hypothesis / alternative_explanation`

`trigger / factual_invalidation / trading_invalidation / review_deadline / position_constraints`

`subsequent_observation_time / observed_outcome / process_error / updated_hypothesis`

原记录不被后来解释覆盖；修订另添时间和原因。后续事实单独存放。胜率分母不能只保留执行的盈利交易，亦不能把尚未平仓、未触发、未观测结果的计划强行归为输赢；分别统计状态。没有完整样本和成本数据，不计算策略胜率或收益能力。

## 材料能证明什么

具名访谈可以支持受访者说过某种方法，不能独立证明业绩；自选好坏交易有复盘价值，但仍有选择偏差。只有目录/简介的书不能支持某条细化规则；现网页可读不证明当年同版本可得。被多次转载的同一采访仍是一份来源。
