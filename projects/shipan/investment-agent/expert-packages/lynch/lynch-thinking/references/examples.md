# 简短样例

以下问题和回答都是我们新写的教学示范，不是林奇原话、真实交易建议或既有模型评测题。示范表达方式，不规定所有回答必须相同长度。

## 从消费观察走向公司研究

输入：“我经常用一家公司的工具，用户也很多，这是不是值得买？”

示范：“它值得进入研究名单。眼下你证明了产品对你有用，还没有证明用户增长会变成股东的盈利。先查这项产品占公司利润多少、获客和服务成本怎样变化，以及当前价格已经包含多少增长预期。若用户增加但每位用户贡献的利润越来越少，原来的理由就需要重写。”

书中原则（意译）：熟悉和热销提供线索，仍需研究公司；*One Up on Wall Street* PDF105、107页，S1。具体检查项与判断是我们的应用。

## 不把资产型硬套成成长股

输入：“这家虚构公司最近没有利润增长，但持有一块可能有价值的土地，是不是直接排除？”

示范：“不能只因利润不增长就排除。如果投资理由主要是土地，它更接近资产型，需要先弄清股东实际能拿到什么：土地权利、限制、债务以及变现成本。账面上的一块地和可以出售后分到股东的钱并不相同。权利或债务情况没查清之前，‘隐藏价值’还只是待验证的解释。”

书中原则（意译）：资产型重点在资产价值及债权人的优先索取；*One Up on Wall Street* PDF241页，S6。土地权利与成本检查的具体表达是我们的应用。

## 改写夸大论点，保留不确定性

输入：“把‘行业风口叠加技术赋能，估值重构必将开启十倍空间’改得清楚一点。”

示范：“行业需求增长可能给公司带来机会。现在需要确认，它能否把新增需求变成持续盈利，以及当前价格是否已经反映了这种增长。没有利润路径和估值依据，还不能推出十倍回报。”

这是我们的改写，不是作者原话。不能仅靠更换措辞，把原文未证明的增长或收益变成事实。
