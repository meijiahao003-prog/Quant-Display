# 每日行情与跨日刷新

页面默认读取真实接口。北京时间的今天日期与行情源日期分别展示，源数据没有更新时不会把昨日数值改成今天。盘前、周末及节假日显示源实际返回的最近记录；本实现没有接入交易所节假日日历，因此不宣称某一历史日一定是“上一交易日”。

## 行为变化

| 场景 | 修改前 | 修改后 |
| --- | --- | --- |
| 成功请求却返回昨日记录 | 可能标为 live | status=stale，同时显示源日期和今天日期 |
| 北京时间跨午夜 | 只依赖普通 60 秒定时器 | 立即重判日期；可见且空闲时重新读取 |
| 页面从后台恢复、恢复联网 | 等下次定时器 | visibilitychange / focus / pageshow / online 请求立即刷新，合并重复事件 |
| 请求进行中跨日或恢复 | 没有排队状态 | 不重叠发起，完成后处理待更新请求 |
| 快照请求失败 | 走势图停在旧画面 | 仍重试独立价格与资金历史接口 |
| 资金排行中混有异日记录 | 可能合并排行 | 仅排列最新实际源日期的记录，显示未纳入数 |
| ETF 价格日与资金日不一致 | 表格可能混合两日数值 | 当行资金显示缺失，保留来源时间和不一致说明 |

页面可见时每 60 秒刷新；关闭后不运行浏览器定时器。重新打开会实时请求上游已有的最新日分钟历史，不需要修改日期或重新部署。无后台定时采集承诺。三专家会审仍保留发起时冻结的输入，不将新行情悄悄替换到旧结论中。

## 函数与步骤

| 函数 / 步骤 | 用途与输入 | 可运行调用 | 输出及处理变化 |
| --- | --- | --- | --- |
| `shanghaiDate` / `withMarketFreshness` | 显式上海日期转换、真实 payload 和可注入时钟 | `node examples/daily-refresh.mjs` | 给已有价格/资金添加日期状态；不改 bars/as_of；详见 `DAILY_REFRESH_BACKEND.md` |
| `createRefreshController` | refresh 回调、now、可见/启用/忙碌状态与跨日回调 | `node --test tests/refresh-controller.test.mjs` | tick/resume 返回是否执行；跨日/恢复触发、60 秒间隔、并发保护 |
| `validateSnapshot` / `loadChart` / `loadFlowHistory` | 接口实际返回的快照或分钟序列 | 打开页面，选择 510300，点击“刷新” | 保留接口实际日期，添加新鲜度；曲线仍按原始分钟绘制 |
| `renderDateStatus` / `renderStatus` | 当前选择的价格与资金源时间、浏览器时钟 | 页面顶部“今天 / 价格日期 / 资金日期”栏 | 今日日期动态计算；历史或缺失时醒目提示，不用抓取时间替代源时间 |
| `renderAll` / `refresh` / `connect` | 当前状态和 /api/snapshot 的实际响应 | 打开页面或点击“刷新”“使用内置免费行情” | 等待所需图表请求；报价失败也尝试独立曲线；记录检查完成时间 |
| `tickClock` / 生命周期事件 | 每秒时钟、visibilitychange/focus/pageshow/online | 保持页面打开、切换浏览器标签后返回 | 每秒显示北京时间，驱动刷新控制器，跨日重新标记旧数据 |
| `api` | 已有同源 API 路径 | 浏览器原有上述动作 | 请求采用 cache=no-store，后端仍使用受控 60 秒缓存 |

## 已执行的真实记录回放

输入为既有 `examples/fixtures/council-market-real.json`，其中 510300 价格 `as_of=2026-10-21T14:05:00+08:00`，187 个真实记录点。检查时钟显式设为 2026-10-22 10:00 CST，这属于真实记录回放，不是当前行情。

```sh
node examples/daily-refresh.mjs
```

实际输出节选：

```json
{
  "before": {"as_of":"2026-10-21T14:05:00+08:00","status":"live","bars":187},
  "after": {"as_of":"2026-10-21T14:05:00+08:00","today":"2026-10-22","source_date":"2026-10-21","status":"stale","freshness":"previous_day","bars":187},
  "observations_unchanged":true
}
```

同一脚本还运行明确合成的午夜时钟：23:59:59 增加 1 秒，实际 refresh_calls=1、elapsed_ms=1000、model_calls=0。没有等待真实午夜，也没有调用任何模型。

## 本次线上接口读取与验证范围

2026-10-22 修改前读取现有生产接口的实际输出：快照 source as_of=09:59:28 CST，16 个标的；510300 价格 source as_of=10:00 CST，31 个点；资金 source as_of=10:00 CST，30 个点。说明上游能返回当天数据，修复的是日期状态、跨日缓存和恢复刷新逻辑。

内部预览已核对动态日期栏和缺失状态布局。预览环境上游请求返回 internal error，因此预览没有声称读取成功；生产接口通过独立认证请求核验。午夜及页面恢复场景由注入时钟测试验证，不冒称已等待到未来日期。

固定演示模式保留其合成情景时间并加强标注；资料核查日期、历史记录和会审冻结时间仍表示它们本来的含义。
