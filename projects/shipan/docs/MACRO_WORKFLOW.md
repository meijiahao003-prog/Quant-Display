# 宏观先导与观市联动

左栏的「看盘」保留行情、自选观察池、ETF 资金排行和大小单结构。「投资建议」是原三专家圆桌的独立页面，继续使用用户本机已登录的工作站。右栏「宏观先导」独立读取每日研究结论，不依赖本机 Agent 在线。

## 日度顺序

晨间任务读取宏观市场监测资料空间、最新版一年数据包与研究手册，更新数据后形成有出处的结论。结论保存至 `/api/macro` 并独立读回，随后调用 `/api/refresh` 更新观市。全部步骤及固定来源身份保存在已部署 `/macro-workflow.json`；新的云任务可直接读取，不依赖此开发目录或旧会话。

北京时间每天早上约 08:00 使用原宏观任务执行这一顺序；原观市任务保留工作日 09:40—15:40 每小时采集，同时核验晨间结论状态，不重复运行全量宏观数据管线。实际任务是否启用以任务工具保存结果为准，源码中的时间说明不会自行创建定时任务。

## 数据边界

- 结论生成日期、市场交易日、月季指标所属期、资料取得时间各自保留。盘前使用最近已公布值；当日无宏观新发布时不制造新证据。
- 资料部分成功时保留成功记录并标出缺口；不足以形成结论时单独写失败状态，不删除旧结论。
- 宏观失败不阻挡行情更新，行情失败不清空宏观先导。两者在页面上各自显示实际日期。
- 手册是研究方法，不将其中固定日历、经验阈值直接当作当期事实。展示副本在 `/macro-handbook.html`，自动研究以 Library 中的最新版为准。
- 既有私有访问范围保持不变；后台每次重新取得本站服务权限，凭据仅在内存和本站请求头中使用。
